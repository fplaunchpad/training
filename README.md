# FP Launchpad Training Materials

This is an index of the courses, workshops, talks and learning resources created by [FP Launchpad](https://fplaunchpad.org) at IIT Madras. Each entry links to the repository that holds the material, and to its website where one exists.

## University courses (IIT Madras)

- **CS3100: Paradigms of Programming** (Monsoon 2025). [Repo](https://github.com/fplaunchpad/cs3100_m25), [website](https://fplaunchpad.org/cs3100_m25/)
- **CS3300: Compiler Design** (Monsoon 2026). [Repo](https://github.com/fplaunchpad/cs3300_m26), [website](https://fplaunchpad.org/cs3300_m26/)
- **CS6225: Programs and Proofs** (Spring 2025). [Repo](https://github.com/fplaunchpad/cs6225_s25_iitm), [website](https://fplaunchpad.org/cs6225_s25_iitm/)
- **CS6868: Concurrent Programming** (Spring 2026). [Repo](https://github.com/fplaunchpad/cs6868_s26), [website](https://fplaunchpad.org/cs6868_s26/)

## Online course

- **Functional Programming in OCaml** (NPTEL). [Repo](https://github.com/fplaunchpad/ocaml_nptel), [website](https://fplaunchpad.org/ocaml_nptel/)

## Workshops and talks

- **Fun and Profit with OCaml**, a beginner workshop at IndiaFOSS 2026. [Repo](https://github.com/fplaunchpad/indiafoss-2026-ocaml-workshop), [website](https://fplaunchpad.org/indiafoss-2026-ocaml-workshop/)
- **Modes in OxCaml**, an internal FP Launchpad talk with live, runnable slides on modes, kinds, unboxed types and SIMD. [Repo](https://github.com/fplaunchpad/oxcaml-talk)
- **Compilers lecture**, an invited talk at the AICTE Compilers short-term course (January 2021). [Repo](https://github.com/fplaunchpad/aicte-compilers-lecture-2021)

## Self-study and community learning

- **IITM OCaml Reading Group**, a weekly group reading Real World OCaml together. [Repo](https://github.com/fplaunchpad/iitm_ocaml_reading_group)
- **Learn2Lean**, an interactive web book that teaches formal verification in Lean 4 by proving school arithmetic algorithms correct. [Repo](https://github.com/fplaunchpad/Learn2Lean)
